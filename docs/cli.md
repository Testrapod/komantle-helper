# 꼬맨틀 헬퍼 CLI

## 시작

가상환경에서 `python -m pip install -e .`로 설치하고 `komantle`을 실행합니다.
Python 3.12 이상이 필요하며, 아카이브 데이터의 사용에는 Java가 필요하지 않습니다.
`python -m komantle_helper` 또는 저장소의 `python main.py`도 같은 앱을 실행합니다.

시작하면 아스키 이모지와 함께 오늘 회차를 준비합니다. 기록이 있으면 바로 이어갑니다.
오늘 데이터가 아직 없으면 최신 보관 회차와 갱신 대기를 명시합니다.
`/round today`로 원본 조회를 시도할 수 있고, `/round`로 다른 회차를 찾을 수 있습니다.

## 입력과 키보드

일반 단어를 입력하고 Enter를 누르면 추측합니다. `/`를 입력하면 명령 팔레트가 열리고
영문 또는 한국어로 검색할 수 있습니다. `/힌트`, `/회차`, `/기록`, `/포기`도 지원합니다.

입력창은 테두리로 구분하며, 단어를 입력할 때는 **단어 추측**, `/`로 시작하면 **명령 입력**으로
표시합니다. 제출한 내용은 실행 기록에 `나 · 추측 #01`, `나 · 명령 #02`처럼 남고, 결과는
같은 번호의 `꼬맨틀 헬퍼 · 응답` 박스로 묶습니다. 오류·선택 대기·확인 대기도 각각 표시합니다.
채점 중 다른 명령을 실행해 응답 순서가 바뀌어도 번호와 명령 표시로 구분할 수 있습니다.
확인창의 승인·취소 결과도 원래 명령 번호에 연결됩니다. 공개 힌트 값은 실행 기록에 남기지 않습니다.

- `Tab`: 완성 후보 선택. 선택한 후보에서 Enter를 누르면 입력을 완성하고, 다시 Enter로 실행합니다.
- `↑↓`: 팔레트/선택기 항목 이동. 팔레트가 닫혀 있으면 이번 실행의 입력 기록 탐색.
- `Esc`: 팔레트나 선택/확인 UI 취소.
- `Ctrl+C`: 입력이나 진행 중인 조회·채점을 취소하고 계속 사용.
- 빈 입력창의 `Ctrl+D` 또는 `/quit`: 종료.

여러 줄을 붙여넣어도 자동 제출하지 않습니다. 한 단어 또는 한 명령으로 수정해주세요.
전체 단어·포기·기록 삭제 확인은 기본 선택이 **취소**입니다. 방향키로 실행 항목을 선택한
뒤 Enter를 눌러야 반영됩니다.

## 힌트와 게임

게임 회차와 힌트 대상 순위는 다릅니다. `/rank 50`은 50위 단어의 힌트를 보여주도록
설정하지만, 추측은 계속 현재 회차의 정답을 대상으로 채점합니다. 0위가 정답입니다.

```text
/rank 0
/hint length
/hint pos
/hint initial
/hint similarity
/hint char 2
/hint word
```

`/hint`는 힌트 종류 선택기를, `/hint char`는 글자 위치 선택기를 엽니다.
글자 위치는 1부터 시작합니다. 한국어로 `/힌트 글자 2`도 가능합니다.
`/hide initial`은 초성만, `/hide`는 모든 힌트를 숨깁니다.
회차나 순위가 바뀌면 공개 상태가 초기화됩니다. 공개한 힌트는 다음 실행까지 저장하지 않습니다.

힌트는 갱신 영역에만 표시합니다. 이미 녹화되거나 터미널에 보관된 스크롤백까지 삭제하는
기능은 아닙니다. `/hint word`는 힌트 공개이고 `/giveup`은 게임 포기와 정답 공개입니다.
힌트로 전체 단어를 봐도 자동으로 포기 처리하지 않습니다.

추측 결과의 유사도는 -100~100 단위입니다. 중복 입력과 채점 실패는 횟수에 포함하지 않습니다.
`/history`는 높은 유사도 순이며 동점은 최근 시도를 먼저 표시합니다.
`/history --sort recent`는 최근 입력 순, `/history --page 2`는 다음 페이지를 표시합니다.
정답을 맞혔거나 포기한 회차도 힌트와 기록은 조회할 수 있습니다.

## 기록과 설정

`/records delete current`는 현재 회차, `/records delete all`은 전체 CLI 회차의 추측 기록과
정답·포기 상태를 삭제합니다. 확인을 취소하면 그대로 유지됩니다. 삭제 후 현재 회차는 새로 시작합니다.
설정이나 데이터 캐시, 웹 브라우저의 기록은 삭제하지 않습니다.

저장이 실패해도 메모리에서는 플레이할 수 있습니다. 화면에 `저장 실패` 상태와 원인을 표시합니다.
`/status`에서 기록 경로, 데이터 출처, 수집 시각과 채점 제약을 확인하세요.

`/settings`에서 색상과 로딩 효과를 켜거나 끌 수 있고 설정은 다음 실행에도 적용됩니다.
`/settings color off`, `/settings animation off`로 직접 바꿀 수도 있습니다.
`/clear`는 화면만 정리하고 게임 기록은 유지합니다. `/links`는 원본 게임과 GitHub 주소를 표시합니다.

| 옵션 | 용도 |
| --- | --- |
| `--round 1667` | 지정한 회차로 시작 |
| `--state-dir 경로` | 기록·화면 설정 저장 폴더 |
| `--cache-dir 경로` | 내려받은 아카이브 캐시 폴더 |
| `--archive-dir 경로` | 공개 웹 대신 로컬 아카이브 사용 |
| `--no-color` | 색상 끄기, `NO_COLOR` 환경 변수도 지원 |
| `--no-animation` | 로딩 효과 끄기 |
| `--ascii` | 이모지 얼굴·입력 프롬프트 등에 ASCII 사용 |
| `--plain` | 커서 제어 없는 일반 텍스트 화면 |
| `--version` | 버전 표시 |

기본 기록·설정 경로는 `~/.local/state/komantle-helper/`이며 `KOMANTLE_STATE_DIR`도 지원합니다.
기본 캐시는 `~/.cache/komantle-helper/`이며 `XDG_CACHE_HOME`을 존중합니다.

## 오프라인과 일반 텍스트 모드

한 번 검증해 내려받은 회차는 네트워크 없이 힌트와 보관 단어 채점을 사용할 수 있습니다.
캐시 목록은 먼저 표시한 뒤 백그라운드에서 갱신합니다. 새로운 오늘 회차가 발견되어도
플레이 중인 회차를 자동으로 바꾸지 않습니다. `/refresh` 실패가 정상 게임 기록을 지우지 않습니다.

원본 직접 조회에서 품사를 분석하려면 `python -m pip install -e '.[analysis]'`와 Java가 필요합니다.
품사를 사용할 수 없어도 다른 힌트와 게임은 계속 사용할 수 있습니다.

입출력이 터미널이 아니거나 `TERM=dumb`이면 자동으로 plain 모드로 전환합니다.
plain 모드에서도 같은 슬래시 명령을 사용합니다. 출력한 힌트를 다시 숨길 수는 없으며,
전체 단어·포기·삭제 같은 확인 명령은 자동 취소합니다. 실제 터미널에서 확인해 실행해주세요.

```sh
python -m scripts.demo_data
komantle --archive-dir .demo-archive --state-dir /tmp/komantle-demo
```

이 모드는 합성 데이터로 화면을 확인하기 위한 것입니다. 보관된 예시 단어 `과일`을 입력하면
네트워크 없이 추측할 수 있습니다. 예시에 없는 단어는 원본 채점 API를 조회합니다.

## 프로젝트 구조

```text
komantle_helper/
  core.py          단어·회차·날짜·지연 품사 분석
  archive.py       수집기와 CLI의 공유 JSON 검증·파일 I/O
  data.py          공개 아카이브·원본 API·캐시
  game.py          채점·게임 세션·파일 기록 관리
  cli/
    app.py         입력·상태·선택 UI와 작업 생명주기
    commands.py    명령 명세·별칭·파서·자동완성
    views.py       시작 화면·힌트 값·기록 표·스타일
    transcript.py  번호로 연결한 입력·응답 박스와 실행 기록
    workers.py     동기 I/O 실행과 취소·빠른 종료
```

숫자 메뉴, 별도 게임 루프와 `--play`는 제거했습니다. 수집기·빌드·테스트는 새 공통 모듈을
직접 참조하며 이전 `main.py` API를 위한 호환 계층은 없습니다.
